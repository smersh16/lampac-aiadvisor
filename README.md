# lampac-aiadvisor

Персональные рекомендации для [lampac-nextgen](https://github.com/lampac-nextgen/lampac): ряды «Для вас» на главной Lampa отдельно для **аниме, мультфильмов, сериалов и фильмов**. История и вкусы категорий не смешиваются.

Работает **без ИИ-сервисов**: кандидаты берутся из TMDB (рекомендации и похожие на просмотренное, подборка по любимым жанрам), затем ранжируются по вашей истории и настройкам. Ничего не отправляется третьим лицам.

## Как это устроено

| Часть | Что делает |
|-------|-----------|
| Плагин `plugin.js` (в браузере) | Читает историю Lampa (`Favorite`, до 100 записей), делит на категории, запрашивает у TMDB кандидатов, ранжирует, показывает ряды |
| Сервер `Controller.cs` | Хранит журнал просмотренного и настройки на пользователя в `database/aiadvisor/{пользователь}.json`. Журнал накапливается, поэтому лимит истории Lampa не мешает |

Категории (по данным карточки TMDB):

- **аниме**: жанр «Мультфильм» (16) и страна JP, CN или KR либо язык оригинала ja, zh, ko (как в lampac-aniskip);
- **мультфильмы**: остальная анимация;
- **сериалы**: сериал без анимации;
- **фильмы**: фильм без анимации.

## HTTP

| Маршрут | Описание |
|---------|----------|
| `GET /aiadvisor.js` | Плагин (`/aiadvisor/js/{token}` для token-варианта) |
| `GET /aiadvisor/data` | `{ seen: {anime,cartoon,tv,movie}, prefs }` текущего пользователя |
| `POST /aiadvisor/seen` | Тело: массив записей журнала |
| `POST /aiadvisor/prefs` | Тело: настройки по категориям |

Пользователь определяется так же, как в остальных модулях Lampac (`token`, `account_email`, `uid`, `profile_id`).

## Установка

1. В `module/repository.yaml` сервера:

   ```yaml
   - repository: https://github.com/smersh16/lampac-aiadvisor
     branch: main
     modules:
       - AiAdvisor
   ```

2. В `init.conf` добавить плагин в `LampaWeb.customPlugins` (элементы уже существующего списка не удалять):

   ```json
   "LampaWeb": {
     "customPlugins": [
       { "url": "{localhost}/aiadvisor.js", "status": 1, "name": "AiAdvisor", "author": "smersh16" }
     ]
   }
   ```

3. Перезапустить контейнер lampac, открыть Lampa и обновить страницу.

Проверка: `curl -s http://СЕРВЕР:9118/aiadvisor.js | head -c 200` возвращает JavaScript; в Lampa на главной появляются ряды «Для вас: …», а в настройках раздел «Рекомендации для вас».

Откат: убрать запись из `repository.yaml` и `customPlugins`, перезапустить контейнер. Данные пользователей остаются в `database/aiadvisor/` и ничему не мешают, их можно удалить.

## Настройки (по категориям)

Показывать ряд · любимые жанры · не показывать жанры · стоп-слова (в названии и описании) · языки оригинала · не старше года · минимальный рейтинг. Жанры вводятся русскими названиями TMDB через запятую (например, `драма, детектив`).

В разделе каждой группы две информационные строки, они заполняются при открытии настроек:

- **Версия плагина**: первая строка раздела, показывается сразу.
- **«Аниме: что видно в истории»** (и так для каждой группы): число записей группы, самые частые жанры и языки (в процентах), годы просмотренного;
- **«Аниме: сейчас применяется»**: какие жанры, языки, рейтинг и год реально используются при подборе и откуда они взяты (из настроек или из истории).

## Ограничения первой версии

- Только ряды на главной, отдельного экрана в меню пока нет.
- История Lampa хранит урезанные карточки без жанров. Плагин дозапрашивает жанры, язык и страну у TMDB по `id` (до 40 записей за раз, самые свежие первыми) и сохраняет их в журнале на сервере, поэтому полный «прогрев» занимает несколько открытий главной. Диагностика: `aiadvisorDebug('anime')` в консоли браузера.
- Языки общей подборки берутся из настройки «Языки оригинала»; для аниме без неё используются ja, zh и ko (аниме не обязательно японское). Остальные группы без настройки язык не ограничивают.
- Предпочтения хранятся на сервере и подтягиваются при старте Lampa; кэш подборки на устройстве живёт 6 часов и сбрасывается при смене настроек.
- Интеграция с главной проверена только по коду `ContentRows` в Lampa 3.2.8; поведение пустого ряда и вид карточек нужно проверить на устройстве.
